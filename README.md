# CampusFlow

"One Place for Your College Life."

## Deskripsi

CampusFlow adalah aplikasi web untuk membantu mahasiswa mengelola kehidupan akademik dan aktivitas kampus dalam satu platform. Proyek ini dikembangkan secara bertahap dari semester 1 hingga semester 8 sebagai portfolio utama studi Informatika.

## Fitur

### Fase 1 (Semester 1)
- Dashboard UI dengan sidebar
- Task management basic
- Responsive design

### Fitur yang akan ditambahkan
- Task creation, edit, delete
- Course management
- Calendar
- Notes
- Academic analytics
- AI assistance (tahap lanjutan)

## Tech Stack

- HTML5
- Tailwind CSS (via CDN)
- JavaScript (Vanilla)
- Git & GitHub

## Project Structure

```
CampusFlow/
├── index.html

├── README.md
└── assets/
```

## Cara Menjalankan

1. Clone repository: `git clone <repository-url>`
2. Buka folder: `cd CampusFlow`
3. Jalankan: Buka `index.html` di browser favorit Anda
4. Atau gunakan Live Server di VS Code

## Roadmap

- Semester 1: HTML + Tailwind CSS + JavaScript + LocalStorage
- Semester 2: Python + Flask + SQLite
- Semester 3: REST API + PostgreSQL + Authentication
- dan seterusnya...
